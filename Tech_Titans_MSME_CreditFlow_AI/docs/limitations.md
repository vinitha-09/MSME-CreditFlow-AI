# Project Limitations and Future Scope

## Current Limitations

1. The application is a demonstration prototype, not a production banking platform.
2. It uses synthetic or manually supplied data.
3. Live bank statement, GST, Udyam and credit bureau integrations are not implemented.
4. Uploaded supporting files may be recorded by filename rather than fully extracted and verified.
5. Risk and fraud findings are based on configured rules, not a validated production ML model.
6. The mock ledger does not perform real banking transactions.
7. Final loan decisions require human review.

## Future Scope

1. Add OCR and document information extraction.
2. Integrate verified external data sources.
3. Add advanced fraud detection and transaction graph analysis.
4. Evaluate ML-based credit risk models using suitable validated datasets.
5. Implement secure authentication and access controls.
6. Add comprehensive audit logging and integration tests.
7. Improve scalability and deployment readiness.
