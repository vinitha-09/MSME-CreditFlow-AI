# Reports

This folder is reserved for demo outputs generated during MSME CreditFlow AI testing.

Save the following files here when needed:
- `CAM_<case_id>.md` — Credit Appraisal Memo for a case
- `agent_messages_<case_id>.json` — agent communication log
- `case_summary.csv` — exported case summary
- `audit_summary.md` — human-review/audit summary

Use synthetic or anonymised data only. Do not save real customer identity, bank,
tax, KYC, or other personal information in this educational prototype.

Note: The current app provides download buttons. Downloaded files are not
automatically written into this folder; save them here manually unless the
application is updated to add automatic report storage.
